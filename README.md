# Rahi Global School

Premium, kids-focused school website built with React, Vite, Tailwind CSS and React Router.

## Setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Replace school assets

Put the real school assets in `public/`:
- `logo.png`
- `favicon.png`
- `images/campus.jpg`
- `images/hero-kids.jpg`
- `images/classroom.jpg`
- `images/playground.jpg`
- `images/library.jpg`
- `images/activities/arts.jpg`
- `images/activities/music.jpg`
- `images/activities/trips.jpg`

Also replace placeholder address, phone and email in `Footer.jsx` and `InnerPages.jsx`.
